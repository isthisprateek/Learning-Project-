//MiddleWares// -> It is an intermediary

MiddleWares in express are functions that come into play after the server receives request and before the response is sent to the client

common Middle ware func -> methodOverride , bodyParser, express.static(built-in middleware) , express.urlencoded
third-party middleware -> cookie parser,helmet,passport, morgan, cors.

(1) middlewares can access the request,response body
(2) chaining is possible. (2-3 middlewares can be used )
(3) middlewares can send response

Middleware func can :
execute any code
make changed to the request and the response objects.
end the request response cycle.
call the next middle func in the stack

next Middleware func is denoted by the variable name next
if the current middleware func doesn't end the request-response cycle, it must call the next() to pass control to the next middleware function.
